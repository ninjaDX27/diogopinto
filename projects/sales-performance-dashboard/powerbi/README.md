# Power BI Desktop — native report build guide

Import CSV files generated by `etl.py`: `FactOrders.csv`, `DimDate.csv`, `DimCountry.csv`, `DimProduct.csv`. Set date columns to Date and numeric Revenue to Decimal Number. Create one-to-many, single-direction relationships from each dimension to FactOrders. Mark DimDate as date table; sort YearMonth chronologically using a suitable year-month numeric key if necessary.

Add measures from [measures.dax](measures.dax). Build **three report pages**:

1. Executive: total eligible sales, orders, active customers, AOV, monthly revenue line.
2. Commercial: order volume by month, AOV trend, repeat customer share; segment by available fields.
3. Markets: revenue by country, concentration percentage and country table.

Add slicers for year and country and test cross-filter interactions. Check summed revenue and distinct invoice count against the ETL printed totals.

**Limitations:** A native binary `.pbix` is not included. The web portfolio demo is HTML/JavaScript, not an embedded published Power BI report. The DominantSKU is an invoice-level classification, **not** accurate per-product revenue. Do not label those measures as SKU sales.
